# Tokens

Os tokens ficam em `src/styles/tokens.css`, em três camadas:

1. **Primitivos:** o valor bruto (`--indigo-700: #33388c`). Nenhum componente usa direto.
2. **Semânticos:** o papel na interface (`--primary: var(--indigo-700)`). Podem mudar num trecho da página, como o foco na faixa índigo.
3. **Ponte para o Tailwind** (`@theme inline`): cada semântico vira classe (`bg-primary`, `text-text-muted`). A paleta padrão do Tailwind está desligada, então `bg-violet-600` não gera CSS: a classe fica no HTML sem efeito nenhum.

## Cores

Cada linha é um papel semântico, com o primitivo para onde aponta e o contraste calculado pela fórmula da WCAG 2.x. Texto pede 4,5:1. Borda de campo e indicador de foco pedem 3:1.

## Tipografia

Duas famílias variáveis, servidas pelo Fontsource, sem chamar serviço externo. A escala é a padrão do Tailwind.

**Fraunces** (`font-display`): `h1`, `h2`, o nome do curso e o preço. **Inter** (`font-sans`): todo o resto.

<Unstyled>

- `h1`: `font-display text-4xl md:text-5xl font-semibold leading-tight`
- `h2`: `font-display text-3xl md:text-4xl font-semibold leading-tight`
- `h3`: `font-sans text-xl font-semibold`
- Corpo: `text-base leading-relaxed` (16 px)
- Texto secundário: `text-sm` (14 px). Nada menor do que isso.
- Campos de formulário com 16 px: abaixo disso, o navegador do iPhone dá zoom ao focar.

## Espaçamento

Base de 4 px (`--spacing: 0.25rem`). Estes são os passos usados; fora deles, só com motivo.

<Unstyled>
  <div className="flex flex-col gap-2 text-text">
    {[1, 2, 3, 4, 6, 8, 12, 16, 24].map((step) => (
      <div key={step} className="flex items-center gap-4 text-sm">
        <code className="w-12">{step}</code>
        <div className="h-4 bg-primary" style={{ width: `calc(var(--spacing) * ${step})` }} />
        <span className="text-text-muted">{step * 4} px</span>
      </div>
    ))}
  </div>
</Unstyled>

Semânticos:

- `py-section`: respiro vertical de cada seção. 4rem, e 6rem a partir de 48rem de largura.
- `max-w-content`: largura máxima do conteúdo, 72rem.
- `max-w-text`: largura máxima de parágrafo, 40rem.
